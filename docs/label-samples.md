# 标签样例图

打开项目目录后，在「管理模板和标签」弹窗中，每个标签名称旁显示一张样例图。
点击缩略图可放大查看，按 Escape 或关闭按钮返回。没有样例图时显示占位。

- 点击「设置样例图」打开选择窗口，列出当前项目中该标签的所有有效标注，当前图片优先显示；支持分页浏览，并保留「从文件选择」入口（PNG、JPG、JPEG 或 BMP）。
- 项目标注显示裁剪后的预览。点击某个标注时，才把对应区域截取成临时 PNG 文件并立即用于草稿预览；浏览列表本身不会生成文件。保存时复制到项目 `icon/`，取消、更换、清除、切换项目及正常退出时清理所生成的临时图。
- 矩形按原图像素坐标截取，多边形使用外接矩形，关键点取周围 64×64 像素。小数边界向外取整，超出图片的部分裁去；完全越界或无效标注不能选择。裁剪保留原图像素，不包含画布上的标注线和文字。
- 「更换」和「清除」只修改当前草稿，点击弹窗中的「保存」才写入项目。
- 「取消修改」放弃样例图及标签草稿；直接关闭弹窗保留草稿，重新打开可继续编辑。
- 样例图也随「另存为」「新增模板」「保存并更新标注」保存；取消命名或确认对话框不会写入图片。
- 内置或插件模板只修改样例图时，可直接保存，无需复制标签模板。
- 未打开项目目录时，样例图区域置灰，其余标签编辑功能可照常使用。

## 目录约定与批量维护

图片保存在项目根目录的 `icon/` 子目录，使用标签名称作为文件名，例如
标签「行人」对应 `icon/行人.png`。文件名匹配不区分大小写，扩展名支持
`.png`、`.jpg`、`.jpeg`、`.bmp`。同一名称只能有一张图，不能同时存在
`行人.png` 和 `行人.jpg`。目录不得是符号链接或 Windows 重解析点。

「打开 icon 目录」会创建目录（如果不存在）并在 Windows 文件资源管理器打开。
可直接批量复制、更换或移走图片。外部修改后关闭并重新打开标签管理弹窗，即可重新读取图片内容；
未保存的图片草稿仍优先显示，可用「取消修改」丢弃草稿。

名称中的 Windows 非法字符 `<>:"/\|?*` 和控制字符替换为 `_`，首尾空白、
尾部句点被去除，`CON`、`AUX`、`COM1` 等设备名称加 `_` 前缀。
清洗后为空或超过 200 个 UTF-16 单元的名称不可用。两个标签清洗后同名
（包括大小写差异）会明确提示冲突，必须改名后才能保存，不会静默共用图片。

标签重命名时，预览继续对应原标签的图片；保存成功后文件同步改名，支持互换名称和仅更改大小写。
删除标签或切换模板不会自动删除目录中的历史图片；需要时用清除操作或资源管理器维护。
若重命名将覆盖另一张未参与本次改名的图片，保存会拒绝并提示冲突。

## 文件保存与范围

单张图最多 16 MiB，单批次原图与新图合计最多 128 MiB；解码宽高各不超过 16384，
解码内存上限 128 MiB。界面预览为长边不超过 256 像素的 PNG，保存保留所选原文件内容。

保存时先写好新图，再备份并移动原图。标签持久化失败会回滚图片；失败后草稿保留以便重试。
进程意外终止或恢复遇到文件锁时，`icon/.label-samples-<进程号>-<事务号>/` 可能保留恢复用文件；
`old-N` 是原图备份，正常完成或回滚后自动清理。该保护不承诺跨进程崩溃的标签与图片原子提交。

样例图完全依赖目录约定，不写入 `LabelConfig`、`LabelTemplate` 或
`my-label-tool.project.json`，不参与标注导出，不提供插件或 Lua 命令接口。
