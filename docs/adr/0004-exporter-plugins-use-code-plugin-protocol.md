# 导出格式插件与预打标插件共用同一代码型进程协议

导出格式扩展实现为代码型插件（外部进程），与预打标插件共用同一套 manifest、权限、协议与故障隔离机制，而不是为导出单独做声明式 JSON 映射。原因：三类插件只有一种代码承载形态，框架只写一遍；声明式映射只能覆盖平铺字段格式，多文件输出（如 VOC 每图一个 XML）、条件逻辑、图像依赖都做不了。现有 custom 导出的声明式字段映射继续作为内置格式存在，不进入插件系统，避免两套机制并存。

**Status**: accepted

**Considered Options**
- 声明式纯 JSON 插件：零代码最安全，但表达能力受限，长期会被迫再上代码型
- 先声明式后代码型：两套机制都要维护，v1 范围扩大

**Consequences**
- 写一个导出插件的最低门槛是能读写 stdin/stdout；插件作者可获得协议 conformance 测试自测
- 内置 custom 格式与插件导出格式在 UI 上并列展示，但实现路径不同，文档需区分
