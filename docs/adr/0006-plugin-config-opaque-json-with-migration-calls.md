# 插件配置以「不透明 JSON + 版本」存入项目，迁移经协议调用

项目配置保存插件状态为 `pluginId + configVersion + config` 三元组，`config` 对宿主不透明；配置版本落后于插件声明时，宿主向插件进程发起 `config.migrate` 调用（迁移期间强制断网），返回的新配置写回项目。失败时项目照常打开，插件配置标记「待迁移」、相关能力降级。拒绝宿主侧声明式迁移规则：表达能力弱（合并、跨版本链式迁移难），且规则与插件代码双份维护。此决策保证旧项目打开不被插件问题阻断，符合故障隔离要求。

**Status**: accepted

**Considered Options**
- 宿主侧声明式迁移规则（JSON 描述字段改名/移动/默认值）：不执行代码最安全，但表达力弱且维护双份真相

**Consequences**
- ProjectConfig 新增可选字段，旧项目配置加载不受影响
- 迁移失败不阻断主流程，但相关插件能力降级直至迁移成功或插件更新
