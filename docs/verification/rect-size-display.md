# 标注框大小显示开关验收

日期：2026-09-23。

## 行为

- 设置中的「标注框大小显示」与「标签名显示」使用相同的三模式开关，互不影响。
- 默认仅标注模式开启；修改立即生效，并通过 localStorage 持久化。
- 仅矩形框内显示原图像素宽x高，无单位；小数最多显示两位，去掉末尾零。仅格式化显示，不修改标注坐标。
- 文本居中、小框自动缩小字号、不接收鼠标事件；画布缩放只改变显示位置及可容纳字号，不改变数值。
- 不修改标注模型、项目配置、导出结构、Tauri commands 或插件契约。
