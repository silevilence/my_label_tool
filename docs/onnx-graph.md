# ONNX 模型结构查看

在「预打标模型库」中点击模型下方的「查看模型结构」，或使用「打开 ONNX 文件查看」选择本地文件。查看器直接读取 ONNX 文件，不需要安装 ONNX Runtime，也不会将模型加入模型库或运行推理。

## 操作

- 滚轮以鼠标位置为中心缩放，拖拽空白或节点平移；「适应视图」显示整个图。
- 点击节点查看属性、输入输出及关联权重。长链模型在全图比例下节点较小，可用「定位节点」下拉框定位并放大。
- 顶部展示输入输出、节点数、张量边数、权重字节总量和算子分布；详情底部可展开模型元数据。
- 按 Esc 或「关闭」退出。窄窗口可以沿画布旁的滚动条滚动到详情面板。
- 模型更新与结构读取共用资源互斥。更新时查看入口不可用；关闭仍在加载的查看器后，需等宿主读取结束才释放资源。

## 数据和推导边界

张量边按每个非空节点输入计算：同一张量被多个节点消费时分别计边，图输入及 initializer 的来源为 `null`。节点 ID 是文件中的节点序号；布局与推导都另行计算拓扑顺序。

蓝色「模型记录」来自文件中的图输入输出、value_info 或 initializer；黄色「展示推导」是静态规则计算的中间形状；灰色「未知」表示不能确定。已有符号维度原样显示，不用推导值覆盖。推导仅用于显示，不进入模型校验、预打标配置或推理契约。

当前推导覆盖标准算子域、opset 11–23 的常见静态结构，包括卷积、池化、激活、逐元素广播、拼接、拆分、形状变换和 Resize。动态输入、自定义域、不支持的规则或不确定的形状参数保留未知；其他独立分支仍继续推导。此功能不是完整的 ONNX checker 或官方形状推导器。控制流子图等复杂属性只显示类型和消息体积，不递归展开。

文件未声明标准 opset 或版本不在支持范围时，顶部明确提示「展示推导未启用」及支持范围；图结构和磁盘记录仍可查看。支持状态由后端返回，界面不自行维护另一份版本范围。

图查看与原有模型元数据解析共用维度解码：确定维度读到相同数值；符号/缺失维度在查看器中保留名称/未知，导入元数据仍按既有契约映射为 `0`，供用户覆写动态输入尺寸。展示字符串与导入哨兵不要求字面相等，也不相互覆盖。

权重信息包含名称、形状、类型和逻辑字节数，不通过 IPC 传输权重内容。外部权重只读元数据，不打开旁路文件；无法计算字节数的类型显示未知。后端只在内部读取少量形状/缩放常量以便推导，不加载 Runtime、不创建会话、不执行模型。

解析器与原有元数据解析共用 `onnx_wire.rs`；损坏、截断、重复张量生产者、悬空输入及循环图会返回错误。新增 `inspect_onnx_graph` 是宿主命令，不在插件协议代理中开放。插件 Schema、宿主 API、业务能力版本、协议版本与主程序版本均未改变；没有新增应用运行时依赖。

规则依据：[ONNX protobuf 定义](https://github.com/onnx/onnx/blob/main/onnx/onnx.proto)、[Conv](https://onnx.ai/onnx/operators/onnx__Conv.html)、[Resize](https://onnx.ai/onnx/operators/onnx__Resize.html)。实现与真实模型核对记录见 [验收记录](verification/onnx-graph.md)。
